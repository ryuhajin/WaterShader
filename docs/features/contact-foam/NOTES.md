## 1. 개념 요약

```text
가까움   = 1 − 수심 / 거품 폭                       // 물 너머 표면이 수면 바로 아래면 1, 폭보다 깊으면 0
가파름   = 1 − |법선.y|                             // 법선은 깊이 버퍼만으로 추정 (이웃 픽셀 위치의 외적)
기울기 마스크 = lerp(1, smoothstep(시작, 끝, 가파름), 기울기 필터)
거품     = smoothstep(문턱 − 부드러움, 문턱 + 부드러움, 가까움 × 기울기 마스크)   // 문턱 = 노이즈로 흔들림
최종     = lerp(6단계 최종, 거품 색 × 들어오는 빛, 거품 × 세기)
```

- 3단계에서 구한 **수심**(앞 패스 깊이를 물 패스가 다시 읽은 값)만으로 경계를 찾는다. 새 패스는 없다.
- 수심만 보면 얕고 평평한 바닥(레일 머리 8cm, 0.2m 받침대 윗면)도 경계로 잡힌다. 그래서 **깊이 버퍼에서 법선을 추정**해 가파른 면에만 거품을 둔다. G-Buffer 없이 화면 공간에서 표면 방향을 추정하는 기법이다 (사용자 결정 2026-11-07: 6B는 깊이 복원, 6C에서 저장 노멀과 비교).
- 폭이 미터 단위라 카메라와 무관하다.
- 노이즈는 `feature/foam-mask`의 `wave_foam` 텍스처. 가장자리가 이어지지 않는 텍스처라 거울 반복으로 읽고, 돌리고 크기를 바꾼 두 번째 읽기를 섞어 대칭을 감춘다.

### 관찰

- **레일 옆면의 흰 선 (Waterfront):** 레일 머리는 수심 8cm라 수면을 뚫지 않지만, 레일 **옆면**은 가파르고 폭(25cm) 안에 있어 얇은 거품 선이 생긴다. 이 방식은 "수면을 뚫는 곳"이 아니라 "수면 바로 아래의 가파른 면"을 찾기 때문이다. 폭을 0.1m로 줄이면 사라지지만 기둥 띠도 얇아진다. 아트 판단으로 남긴다.
- **노을에서는 거품이 잘 안 보인다:** 거품 색에 장면 빛(환경광 + 햇빛 × 태양 높이)을 곱해서, 해가 낮은 Sunset에서는 거품이 어두운 회색이 된다. 물리적으로는 맞지만 경계 단서로서는 약하다.
- **화면 공간의 한계:** 띠는 카메라 쪽에서 보이는 잠긴 면에만 생긴다. 수면 위로 바깥쪽으로 퍼지는 고리는 없다 (SPEC 5절).
- **거품이 물체 표면에 붙어 보인다 (사용자 검증, 2026-11-07):** 이 방식은 "수면 아래 폭만큼의 벽면"을 칠하므로 물을 통해 벽에 흰 띠를 칠한 모양이 된다. 물 표면 위에서 물체 바깥으로 퍼지는 고리를 그리려면 물체까지의 **수평 거리**가 필요하다 (화면 공간 탐색, 또는 위에서 내려다본 접촉 맵 패스). **사용자 결정: DX11에서는 지금 방식 그대로 두고, 언리얼 단계에서 거리장(`DistanceToNearestSurface`)으로 수면 고리를 만들 때 고친다.**
