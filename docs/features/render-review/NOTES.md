## 4. 고친 것

### 4-1. 하강광 감쇠 (`scene.hlsl` `UnderwaterLightFade`)

```text
빛이 바닥을 지나 눈에 오기까지 물을 두 번 지난다:
  ① 해 → 수면 → 바닥   (새로 넣음)   햇빛 × exp(−소광 × 수심 / cos 굴절각),  하늘빛 × exp(−소광 × 수심)
  ② 바닥 → 수면 → 눈   (4단계부터)   × exp(−소광 × 시선 경로)
굴절각: sin(물속) = sin(물 밖) ÷ 1.33   (평평한 수면 기준, 해가 수직에 가깝게 꺾임)
```

- 물 영역 안, 수면 아래 점만 해당한다 (파도 높이는 정답지와 같은 `WaterDepthBelowSurface`). 모든 파도 마루보다 높으면 높이 계산을 건너뛴다.
- 물이 그려지고 빛을 줄이는 모드(Attenuation / Scattering)에서만 켜진다. Pass-through, 물 끔, Old water는 공기 중과 같다.
- Light 창 Underwater Light > **Sunlight fades on the way down** (기본 켬), CLI `--downwelling on|off`. 사용자가 직접 비교해 보고 끌지 결정한다.

**측정** (Water Lab, 평평한 물, 굴절·반사·거품 끔, Attenuation만, 톤 커브 없음, 켬 ÷ 끔 비율, Clear 물 소광 0.35 / 0.07 / 0.03, 해 고도 43.5° → 물속 33.0°):

| 받는 면 | 켬 ÷ 끔 (R / G / B) | 미터당 감쇠 (R / G / B) |
|---|---|---|
| 받침대 0.2 m | 0.922 / 0.989 / 0.987 | 0.41 / 0.06 / 0.07 (8비트 오차) |
| 받침대 1 m | 0.673 / 0.921 / 0.966 | 0.396 / 0.083 / 0.034 |
| 받침대 3 m | 0.299 / 0.783 / 0.904 | 0.402 / 0.081 / 0.034 |
| 받침대 6 m | 0.089 / 0.618 / 0.820 | 0.404 / 0.080 / 0.033 |
| 바닥 8 m | 0.041 / 0.530 / 0.770 | 0.399 / 0.079 / 0.033 |

미터당 감쇠가 깊이와 상관없이 일정하고, 하늘 값(0.35 / 0.07 / 0.03)과 해 값(0.418 / 0.084 / 0.036) 사이에 놓인다 (밝기 대부분이 햇빛이라 해 값에 가깝다). 8 m 바닥은 빨강 4%, 초록 53%, 파랑 77%만 남아서 더 어둡고 푸르다.

### 4-2. 노멀맵 접선틀 직교화 (`PixelShader.hlsl`, 테스트 장면만)

잔물결 맵의 가로·세로 축이 월드 X·Z로 평평하게 고정되어 있어서, 기운 파도 면에서는 축이 면을 비스듬히 뚫었다. 이제 축도 파도 면을 따라 기운다: X' = normalize(X − N × dot(N, X)), Z' = X' × N (평평한 물에서는 +Z).

- 기존 바다는 정확히 같은 화면을 지키려고 그대로 뒀다 (`#if SCENE_INPUTS`).
- 효과: Lab 파도(진폭 cm 단위)에서는 노멀이 0.45° 미만으로 돈다. Debug 2(8비트, 0.45° 단위)에서는 차이 0이다. 화면 차이는 거의 다 1레벨 이하이고, 아주 날카로운 태양 반짝임(글린트) 점에서만 크게 바뀐다(최대 178레벨). 파도를 크게 하면 효과가 커진다.

### 4-3. F0를 굴절률에서 계산하는 옵션

- 지금 F0는 Water 창 > Reflection (both versions) > "Reflectivity head-on (F0, real water = 0.02)" 슬라이더 값이고, 프리셋에 저장된다(Basic 0.04, Sunset 0.151, Tropical 0.02).
- 그 아래 **F0 from IOR (1.33 → 0.020)** 체크박스 (기본 끔, 세션 설정, CLI `--f0-from-ior on|off`). 켜면 슬라이더가 잠기고 F0 = ((n − 1) / (n + 1))².
- 측정 (lab_top 화면 중앙의 반사량, 거의 수직, Debug 17): Basic 0.027 → 0.016, Sunset 0.043 → 0.004, Tropical 0.016 → 0.016(원래 0.02라 같음). 반사량 = F0 × Reflection strength라서 프리셋마다 세기가 곱해져 있다.
