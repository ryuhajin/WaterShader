# Render Review — 10단계 전 물 렌더링 계산 점검

> Branch: `feature/render-review` · Status: 구현 · Updated: 2026-11-09 · 기록: [NOTES.md](NOTES.md)
> 9단계(그림자)와 10단계(코스틱) 사이. 앞 단계: [../sun-shadow/NOTES.md](../sun-shadow/NOTES.md)

## 1. Goal

- **한 문장 요약:** 물 렌더링 계산(빛·굴절·감쇠·산란·Fresnel·그림자·좌표 변환)을 실무 엔진과 비교해 점검하고, 빠진 식과 틀린 좌표틀을 고친다.
- **스코프 가드:** 렌더링 계산 코드만 본다. 성능 측정 없음(요청 시만). 기존 바다 화면은 바이트 동일하게 유지한다.

## 2. 고칠 것 (사용자 결정 2026-11-09)

| # | 내용 | 기본값 |
|---|---|---|
| 1 | **하강광 감쇠:** 물속 물체가 받는 햇빛 × exp(−소광 × 수심 / cos 굴절각), 하늘빛 × exp(−소광 × 수심). Light 창 Underwater Light에 켬/끔, CLI `--downwelling on\|off` | 켬 (사용자가 직접 비교해 보고 결정) |
| 2 | **노멀맵 접선틀 직교화:** 잔물결 맵의 가로·세로 축을 파도 면에 맞춤 (Gram-Schmidt). 테스트 장면만 | 항상 |
| 3 | **F0를 굴절률에서 계산하는 옵션:** ((n − 1) / (n + 1))², 1.33 → 0.020. Water 창 Reflection, CLI `--f0-from-ior on\|off` | 끔 (프리셋 F0 유지) |

**하지 않을 것:** 거품에 수면 그림자 곱하기(사용자 결정), 산란 위상 함수(제안만, 원하면 추가), SSR(8B), 파도 분산 관계, 하늘 판정 깊이값 개선(기록만).

## 3. Acceptance Criteria

- [ ] 빌드 경고 0, 디버그 레이어 경고 0, 기존 바다 21장 바이트 동일
- [ ] 하강광 끔 + 이전 접선틀 = 9단계 화면과 같음
- [ ] 평평한 물에서 깊이별 미터당 감쇠가 일정하고, 하늘 값(소광)과 해 값(소광 / cos 굴절각) 사이
- [ ] F0 옵션 끔 = 지금 화면, 켬 = 굴절률 값
- [ ] 검토 결과(좌표 변환 표, 누락 목록)를 NOTES에 기록
