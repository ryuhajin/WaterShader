# Caustics — 10단계 물속 바닥의 빛 무늬

> Branch: `feature/caustics` · Status: 구현 완료, 사용자 검증 대기 · Updated: 2026-11-10 · 기록: [NOTES.md](NOTES.md)
> waterfront 업그레이드 10단계. 앞 단계: [../sun-shadow/NOTES.md](../sun-shadow/NOTES.md), [../render-review/NOTES.md](../render-review/NOTES.md)

## 1. Goal / Visual Target

- **한 문장 요약:** 물결진 수면이 렌즈처럼 햇빛을 모았다 흩었다 하며 물속 바닥·계단·물체에 그리는 밝은 그물무늬(코스틱)를, 바닥에 붙어서 일렁이게 그린다.
- 무늬는 **받는 면에 붙는다**: 카메라를 움직여도 바닥 위 같은 자리에 있고, 시간에 따라 모양만 바뀐다.
- **햇빛의 일부**로 다룬다: 그림자 속(9단계)과 물 밖에서는 없고, 깊을수록 약해진다(하강광 감쇠, render-review).
- 레퍼런스: 사진 1(바닥에 붙어 움직이는 코스틱), 레퍼런스 낮 장면(촘촘하고 또렷한 바닥 일렁임).
- **스코프 가드 — 만들지 않을 것:** 실제 파도 메시에서 빛을 굴절시켜 모으는 물리 계산(코스틱 맵), 물속 빛줄기(볼륨), 수면 위 물체에 비치는 반사 코스틱, 기존 바다 화면 변경, 성능 측정(요청 시만). 파도와 물리적으로 일치하는 무늬라고 주장하지 않는다(PLAN 10단계 결정).

## 2. 방법

```text
불투명 장면 셰이더 (scene.hlsl), 받는 점 p마다:
  물 영역 안, 수면 아래인가?          아니면 무늬 없음 (1)
  투영 좌표 uv   = p.xz 를 굴절된 햇빛 방향을 따라 수면까지 거슬러 올라간 자리   (수직 투영은 비교용)
  무늬 c         = 이음매 없는 코스틱 텍스처 2장을 서로 다른 방향으로 흘려 합성 (0 ~ 1)
  깊이에 따른 모양 = 얕으면 선명, 깊을수록 굵고 흐리게 (밉 / 큰 스케일) + 세기 감소
  햇빛 항        = 햇빛 × 각도 × 그림자 × 하강광 × (1 + 세기 × (c − 평균))       // 평균 밝기는 그대로
```

- **수심 (사용자 결정 2026-11-10: 대비가 사라지는 깊이 기본 5 m):**

  | 무엇이 | 어디서 처리 | 5 m 슬라이더와의 관계 |
  |---|---|---|
  | 수면 바로 아래는 아직 빛이 덜 모임 | 코스틱: 0 → 0.1 m에서 세기 0 → 1 | 무관 |
  | 크고 작은 물결 무늬가 겹쳐 뭉개짐 | 코스틱 (근사): 깊을수록 밉으로 흐리게 + 대비 = 1 − smoothstep(0.5 m, 5 m, 수심). 5 m 넘으면 무늬 없음, 평평한 햇빛 | **이 슬라이더** |
  | 햇빛이 내려오며 약해짐 | 하강광 감쇠 (render-review, 이미 있음) | 무관, 5 m 넘어서도 계속 |
  | 물색이 위에 덧칠됨 | 물 패스의 시선 경로 산란 (5단계, 이미 있음) | 무관, 바닥 수심이 아니라 시선 경로 길이로 |

- **평균 보존:** 렌즈는 빛을 만들지 않고 옮긴다. 밝은 선이 생긴 만큼 사이가 어두워져야 하므로 `c − 평균`을 더한다. 세기를 올려도 바닥 전체가 밝아지지 않는다.
- **그림자·물 밖:** 햇빛 항에 곱하므로 그림자(9단계)와 물 밖에서 자동으로 0. 하강광 감쇠 끔 / Pass-through에서는 깊이 감쇠 없이 무늬만.
- **벽(계단 옆면):** 햇빛 방향 투영이라 벽에도 비스듬히 늘어난 무늬가 붙는다. 해를 등진 면은 각도 항이 0이라 무늬 없음.
- **물이 보여 주는 경로:** 코스틱은 바닥 색의 일부가 되어 물 없는 장면 색 복사본에 들어가고, 물 패스의 굴절·감쇠를 그대로 받는다 (PLAN 3장 설계).

**무늬 만들기 (제안: 6B+ 거품 마스크처럼 굽기)**

| 안 | 내용 | 장단점 |
|---|---|---|
| **A. 컴퓨트 셰이더로 구운 텍스처 (제안)** | `foam_bake.hlsl` 방식으로 고정 시드·주기 보로노이 셀 경계 무늬를 512²에 굽고 DDS(밉)로 저장. 실행 중에는 2장 흘려 읽기만 | 싸고, 밉으로 깊이 흐림이 공짜. 아티스트가 그린 텍스처로 바꿔 끼우기 쉬움 |
| B. 셰이더에서 매 픽셀 계산 | 보로노이 9칸 × 2장 | 해상도 무한, 대신 매 픽셀 비용과 먼 곳 반짝임(밉 없음) |

## 3. 디버그·도구

| 이름 | 내용 |
|---|---|
| Light 창 **Caustics** 대분류 | 켬/끔, 세기, 무늬 크기(m), 흐름 속도, 선명도, 깊이 흐림, 투영(태양 방향 / 수직), 무늬 정지(시간 고정) |
| Scene Debug **6** | 코스틱 배율 (회색 = 1, 밝음 = 모임, 어두움 = 흩어짐), 물 숨김 |
| CLI | `--caustics on\|off`, `--caustics-strength`, `--caustics-freeze on\|off` |

## 4. Acceptance Criteria

**에이전트 검증**

- [ ] 빌드 경고 0, 디버그 레이어 경고 0, 기존 샷 21장 바이트 동일
- [ ] 코스틱 끔 → 9단계(render-review 머지 후) 화면과 바이트 동일
- [ ] 바닥에 붙음: 시간 고정, 카메라 두 위치에서 같은 바닥 점의 무늬 값이 같음 (Scene Debug 6)
- [ ] 물 밖·그림자 속에서 배율 1 (무늬 없음)
- [ ] 평균 보존: 넓은 바닥 영역의 평균 밝기가 켬 / 끔에서 거의 같음 (1% 이내 목표)
- [ ] 깊이: 0.2 m / 1 m / 3 m / 6 m 받침대에서 무늬 대비가 깊을수록 줄어듦 (수치)
- [ ] 시간에 따라 모양이 바뀜 (서로 다른 시간 캡처)

**사용자 검증**

- [ ] 무늬가 바닥·계단·자갈에 붙어 있고 카메라를 따라 미끄러지지 않는다
- [ ] 물 밖·그림자에서 사라지고, 깊은 곳에서 약해진다
- [ ] 코스틱이 왜 "햇빛의 재배치"인지(평균 보존), 왜 그림자·하강광 다음 단계인지 설명할 수 있다

## 5. Notes

- 언리얼 대응(14단계): 같은 텍스처를 태양의 Light Function에 연결, 물 영역·수면 아래 마스크, 엔진 그림자 사용.
- 실제 집광 계산(파도 메시 → 바닥, 면적 변화 = 밝기)은 이번 범위 밖. 필요하면 별도 단계로.
- 성능 측정은 하지 않는다 (요청 시만).
