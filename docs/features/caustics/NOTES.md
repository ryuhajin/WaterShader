## 1. 개념 요약

```text
불투명 장면 셰이더 (scene.hlsl), 받는 점 p마다:
  수심 d     = 파도 수면 높이 − p.y   (물 영역 밖 / 수면 위 = 0 → 무늬 없음)
  수면 자리  = p.xz + 오프셋 × d       // 물속에서 꺾인 햇빛을 거슬러 수면까지 (Snell: 옆 성분 ÷ 1.33)
  무늬 c     = 구운 코스틱 텍스처, 두 크기의 휘어짐 + 느린 흐름 (시간)
  평균 a     = 같은 텍스처의 1 × 1 밉 (무늬 전체의 평균)
  배율       = 1 + 세기 × 대비(d) × (c ÷ a − 1)          // 평균이 1: 빛을 옮길 뿐 만들지 않음
  햇빛 항    = 햇빛 × 하강광 감쇠 × (각도 × 그림자 × 배율)
```

**수심에 따른 모양** (사용자 결정 2026-11-10: 대비가 사라지는 깊이 5 m)

| 무엇이 | 어디서 | 수심 |
|---|---|---|
| 수면 바로 아래는 아직 빛이 덜 모임 | 코스틱 | 0 → 0.1 m에서 세기 0 → 1 |
| 크고 작은 물결 무늬가 겹쳐 뭉개짐 (근사) | 코스틱 | 대비 = 1 − smoothstep(0.5 m, 5 m, d), 밉 흐림 + 2.5 × (d ÷ 5 m) |
| 햇빛이 내려오며 약해짐 | 하강광 감쇠 (render-review) | 5 m와 무관, 계속 |
| 물색 덧칠 | 물 패스 산란 (5단계) | 바닥 수심이 아니라 시선 경로 길이 |

- **그림자·물 밖:** 햇빛 항 안에서 곱하므로 그림자(9단계) 속과 물 밖에서는 자동으로 없음.
- **물을 통해 보이기:** 코스틱은 바닥 색의 일부 → 물 없는 장면 색 복사본 → 물 패스의 굴절·감쇠·물색을 그대로 받는다.
- 실제 파도에서 빛을 모으는 계산이 아니다 (PLAN 10단계 결정). 무늬 모양은 파도와 일치하지 않는다.

## 2-1. 큰 파도와 맞추기 (사용자 검증 피드백, 2026-11-11)

**피드백:** "수면의 출렁임이랑 코스틱의 출렁임이 다르게 움직여서 자연스럽지 않다." 원인: 수면은 노멀맵 두 장의 흐름 + Gerstner 파도 4개로 움직이는데, 코스틱은 그와 무관한 자체 흔들림·대각선 이동을 썼다. 고칠 안 세 가지 중 **큰 파도와 맞추기**를 먼저 적용 (사용자 선택). 잔물결(노멀맵) 흐름과 맞추기, 수면 곡률에서 직접 계산하기는 보류.

```text
빛이 들어온 수면 자리 s에서, 물 메시와 같은 파도 함수(같은 방향·파장·속도·거리 감쇠·물 가장자리 감쇠):
  기울기 g = Σ A k cos(위상) × 방향          곡률 c = − Σ A k² sin(위상)
  렌즈 길이 L = 수심 × (1 − 1/n)              // n = 1.33 → 수심의 25 %
  흔들림:  무늬 좌표 = s − 흔들림 × L × g      // 기운 수면이 빛을 옆으로 보냄 (Snell, 8단계 굴절과 같은 식)
  빛 띠:   배율 × (1 − 빛띠 × 대비(수심) × L × c)   // 마루(볼록, c < 0) = 빛이 모임, 골 = 흩어짐
```

- 빛 띠는 면적비 1 ÷ (1 + L × c)의 1차 근사라 파도 한 주기 평균이 1 → 평균 밝기 보존이 그대로 유지된다. 수심이 깊을수록(렌즈가 길수록) 띠가 강해지다가, 5 m 대비 감소(사용자 결정)와 함께 줄어든다.
- 흔들림·빛 띠 모두 기본 1 = 물리값. Light 창 Caustics > **Follow the big waves**: Wave sway, Wave light bands (0 ~ 3). Scene Debug **7** = 빛 띠만.
- View 창 Lab Waves를 끄면 따라갈 파도가 없어 둘 다 사라진다.

## 4. 관찰과 한계

- **노을 프리셋:** 해가 낮고 계단 뒤쪽에서 비춰 lab_stairs에서는 코스틱이 거의 안 보인다(햇빛을 받는 면이 적음). 정상.
- **무늬와 잔물결은 아직 따로 논다:** 큰 파도와는 2-1로 맞췄지만, 그물무늬 자체의 흐름은 노멀맵 잔물결과 방향·속도가 다르다. 다음 후보: 코스틱 두 장을 노멀맵 두 장과 같은 속도·방향·회전으로 흘리기(A-1), 또는 수면 곡률에서 직접 계산(B).
- **정지 화면에서는 2-1이 잘 안 보인다:** 흔들림(1 m 수심에서 최대 약 8 cm)과 빛 띠(±25 %)는 움직일 때 드러난다.
- **흐름 속도를 바꾸면 무늬가 한 번 튄다:** 시간 × 속도라서. 슬라이더를 움직이는 순간만.
- **물속 시선 굴절과 무늬:** 무늬는 바닥에 붙어 있고, 물이 그 바닥을 굴절시켜 보여 주므로 화면에서는 물결 따라 일렁인다(8단계 굴절).
