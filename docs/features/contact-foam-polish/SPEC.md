# Contact Foam Polish — 6B++ 접촉 거품 다듬기

> 6B(접촉 거품) 보강. 원래 설계: [../contact-foam/SPEC.md](../contact-foam/SPEC.md), 무늬: [../foam-masks/SPEC.md](../foam-masks/SPEC.md)

## 1. Goal

- **한 문장 요약:** 접촉 거품을 레퍼런스 글(https://fire-face.com/water/)의 기법으로 다듬는다. 두께 바이어스, 접점을 부드럽게 하는 leading edge, 파도를 따라 출렁이는 무늬를 넣고, 거리 재는 방식(수직 수심 / 시선 경로)을 비교할 수 있게 한다.
- **배경:** 지금 거품은 "물 픽셀 뒤에 보이는 면"의 수심으로 정해진다. 그래서 카메라 쪽 벽에만 띠가 칠해지고, 직각 모서리 바깥과 기둥 옆·뒤는 비어 있다. 레퍼런스도 같은 깊이 기반 방식이며, 모서리 문제를 "주된 단점"으로 받아들이고 고치지 않았다.
- **스코프 가드:** 모서리 바깥·기둥 둘레 고리는 만들지 않는다. 위에서 본 거리장은 나중 단계에서 한다(사용자 결정 2026-11-19). 폼 마스크, 코스틱, 성능 측정(요청 시만)도 다루지 않는다.

## 2. 방법

| 항목 | 계산 | 레퍼런스 대응 |
|---|---|---|
| Edge bias | 가까움 = saturate(1 − d ÷ 폭 + 바이어스). 띠가 두껍고 단단해지고, 폭에서 끊긴다 | falloff bias |
| Leading edge | d < 폭 × L이면 lead = d ÷ (폭 × L). 물과 거품을 합친 결과를 그 픽셀의 장면 색 쪽으로 섞어 접점 선을 부드럽게 한다 | `alpha *= leading` (여기는 알파 블렌딩이 없어 직접 섞음) |
| Foam rides the waves | 무늬 좌표를 변위 전 수면 위치에서 잰다. Gerstner 수평 이동을 따라 무늬가 출렁인다 | 정점에 묶인 surface UV |
| Depth measure (비교용) | d = 수직 수심(기존) / 시선 경로 길이 | 장면 깊이 − 수면 깊이 |

- 모두 0 또는 끔이면 지금 화면과 바이트까지 같다.
- 새 처리는 `band`와 최종 합성 안에서 끝나므로, 폼 마스크(맵 1~4)와 옛 구름 노이즈(맵 0)가 그대로 함께 동작한다.

## 3. Acceptance Criteria

**에이전트 검증**

- [ ] 빌드 경고 0, 디버그 레이어 경고 0, 기존 바다 21장 바이트 동일
- [ ] 새 항목 모두 끔 → 이전 화면과 바이트 동일 (6샷 × 3프리셋)
- [ ] 바이어스·leading edge·무늬 따라가기의 전후를 같은 샷으로 캡처하고 수치로 확인
- [ ] 수직 수심은 카메라 높이와 무관하고, 시선 경로는 카메라 각도에 따라 띠 폭이 바뀜을 수치로 확인
- [ ] 데브로그용 캡처 세트와 README를 `ws-capture/contact-foam-polish/captures/`에 정리

**사용자 검증**

- [ ] 접점 선이 부드러워지고 띠 두께를 조절할 수 있다
- [ ] 거품 무늬가 파도를 따라 출렁인다
- [ ] 두 측정 방식의 차이와, 모서리·고리가 남는 이유를 설명할 수 있다
