# Water Scatter — 5단계 산란색 근사 + 깊이 색 램프

> Branch: `feature/water-scatter` · Status: done · Updated: 2026-11-01
> waterfront 업그레이드 5단계. 앞 단계: [../rgb-attenuation/NOTES.md](../rgb-attenuation/NOTES.md)

## 1. Goal / Visual Target

- **한 문장 요약:** 4단계에서 빠져나간 만큼 **물이 스스로 띠는 색**으로 채운다. 깊을수록 바닥 대신 물색이 보인다.
- 물색을 정하는 방식 두 가지를 만들고 같은 화면에서 비교한다.
  - **물리 모드**: 색 하나(산란색). 4단계 투과율과 짝을 이뤄, 경로가 길수록 그 색에 수렴한다.
  - **램프 모드 (아트)**: 얕음 / 중간 / 깊음 3색과 경계 깊이(m)를 직접 지정. 채도 높은 청록 → 파랑 같은 스타일라이즈드 물을 아티스트가 의도대로 칠한다.
- 물 종류 버튼: **맑은 물**, **초록빛 물**(레퍼런스 사진 2), **라군(램프)** — 소멸 계수와 물색을 한 번에 설정.
- **스코프 가드 — 만들지 않을 것:**
  - 반사·Fresnel (6단계) — 이번 단계 화면은 "반사 없이 물속만 본" 상태
  - 빛줄기·볼륨 그림자 같은 진짜 체적 산란
  - 흡수와 산란을 물리적으로 따로 맞추는 모델 (아트 근사라고 명시)

## 2. HLSL 접근법 / 수식 / 의사코드

```text
물 아래 색 = 물 없는 장면 색 × 투과율  +  물색 × (1 − 투과율)
             └── 4단계 (빠져나감) ──┘     └── 5단계 (채움) ──┘
```

- **투과율이 1**(물이 얕음): 바닥색 그대로, 물색 0.
- **투과율이 0**(아주 깊음, 바닥 없음): 바닥색 0, 물색 그대로. → 4단계의 "검정"이 물색이 된다.
- 채널마다 따로: 빨강 투과율이 먼저 떨어지므로 물색의 빨강 몫이 먼저 채워진다.

**물색 = 산란색 × 물에 들어오는 빛**

```text
물에 들어오는 빛 = 하늘빛(환경광) + 햇빛 × 태양 높이(0 ~ 1)
```

- 산란색은 0~1 "물의 반사율" 같은 값이고, 장면 조명을 곱해 불투명 물체와 같은 밝기 단위가 된다. 노을 프리셋에서는 물색도 저절로 어두워지고 붉어진다.

**램프 모드** — 산란색 자리에 3색 램프를 쓴다.

```text
x = 램프 기준 거리 (기본: 수직 수심 / 선택: 시선 경로)
램프색 = 얕음 → 중간 (0 ~ 경계1 m) → 깊음 (경계1 ~ 경계2 m), smoothstep으로 이음
물 아래 색 = 바닥색 × 투과율 + 램프색 × 들어오는 빛 × (1 − 투과율)
```

- **수직 수심 기준**: 카메라를 움직여도 같은 바닥은 같은 색 (얕은 철로는 늘 청록, 깊은 곳은 늘 파랑) — 스타일라이즈드 물에서 흔한 "수심 지도" 느낌.
- **시선 경로 기준**: 낮게 볼수록 깊은 색 — 물리 모드와 같은 성질.

**디버그 뷰**

| 번호 | 이름 | 내용 |
|---|---|---|
| 15 | Inscatter only | 물색 × (1 − 투과율) 만 (바닥 기여 0) |
| 16 | Ramp color | 램프색 그대로 (빛·투과율 없이) |

**참고 자료**

- 물 아래 색 공식(대기 원근의 같은 형태) — Hoffman & Preetham, "Rendering Outdoor Light Scattering in Real Time" (2002)
- 스타일라이즈드 물의 수심 그라디언트 — Alan Zucconi / Roystan "Toon Water Shader" (깊이 차이로 얕은/깊은 색 보간), https://roystan.net/articles/toon-water/

## 3. Inputs / Outputs

| 종류 | 이름 | 형식 | 범위 / 비고 |
|---|---|---|---|
| CBuffer | `g_ScatterColor` | float4 | rgb = 산란색(0~1), a = 세기 |
| CBuffer | `g_RampShallow/Mid/Deep` | float4 ×3 | rgb 색 |
| CBuffer | `g_RampParams` | float4 | x = 경계1(m), y = 경계2(m), z = 기준(0 수심, 1 경로), w = 모드(0 물리, 1 램프) |
| Preset | `scatterR/G/B`, `scatterStrength`, `ramp*`, `waterColorMode` | float | 소멸 계수와 세기가 모두 0(키 없음)이면 Clear로 시작. 세기만 0이면 4단계 화면 그대로 |
| ImGui (Water 창) | Underwater Color | | 모드, 산란색·세기, 램프 3색·경계 2개·기준, 물 종류 버튼 3개 |
| ImGui (View 창) | Transmission | combo | ... / **Scattering** (테스트 장면 기본값) |
| CLI | `--scatter r,g,b,s` / `--water-type clear\|green\|lagoon` | | 캡처용 |
| 도구 | `compare_depth.ps1 -Mode sum` | | 선형 공간에서 `감쇠 화면 + 물색 화면 = 최종 화면` 확인 |

**의존하는 다른 feature:** `rgb-attenuation` (투과율), `depth-reconstruct` (수심·경로)

## 4. Acceptance Criteria / Test Plan

**에이전트 검증**

- [x] 빌드 경고 0, 디버그 레이어 경고 0, 기존 샷 21장 바이트 동일
- [x] 산란 세기 0 → 4단계 감쇠 화면과 바이트 동일
- [x] 소멸 계수 0 → 물색이 아무리 진해도 투과 화면과 바이트 동일 (`1 − 1 = 0`)
- [x] 톤 곡선 끈 선형 화면에서 `감쇠만 + 물색만 = 최종` (8비트 반올림 안)
- [x] 바닥 없는 픽셀·아주 깊은 픽셀 = 물색 (투과율 ≈ 0)
- [x] 받침대별 체크무늬 대비가 얕을수록 남고 깊을수록 사라짐 (0.2m > 1m > 3m > 6m)

**사용자 검증**

- [x] 깊은 계단은 물색에 섞이지만 얕은 체크무늬는 유지된다
- [x] 산란 OFF(4단계)와 ON의 차이를 설명할 수 있다
- [x] 물리 모드와 램프 모드의 차이, 램프를 수심 기준으로 할 때와 경로 기준으로 할 때의 차이를 설명할 수 있다
