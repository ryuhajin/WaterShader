# Refraction — NOTES

> 8단계 진행 기록. 상태: **에이전트 검증 완료, 사용자 승인 대기**

## 1. 개념 요약

```text
꺾인 방향 r = refract(시선, 수면 노멀, 1 / 1.33)          // 수면 노멀 = 파도 + 잔물결
P = 수면 점 + r × 거리 → 화면에 투영 → 그 픽셀의 깊이로 물속 표면 → 거리 갱신 (4회)
실패하면 (화면 밖 / 수면 위 표면 = 전경 누출) 세기를 ½, ¼로 줄여 다시 → 그래도 실패면 원래 픽셀
고른 픽셀 하나로 장면 색, 표면 위치, 수심, 경로, 투과율, 물색, 거품을 모두 다시 계산
```

- 평평한 물도 시선을 꺾는다. 깊은 바닥이 실제보다 얕고 가까워 보이고(겉보기 깊이), 물에 들어간 계단·기둥이 수면선에서 꺾인다.
- 수면선 바로 아래는 물속 거리 ≈ 0이라 이동도 ≈ 0. 접촉선에서 저절로 0이 된다.
- 굴절은 수면 노멀이 필요해서, 노멀 계산을 픽셀 셰이더 맨 앞으로 옮겼다 (기존 바다 프로그램은 문장 순서가 같아 그대로).

### 과정에서 고친 것

| 증상 | 원인 | 해결 |
|---|---|---|
| 낮은 시점(front_rails)에서 물의 절반가량이 "전경 누출"로 판정되어 굴절이 꺼짐 | 굴절로 찾은 픽셀의 장면 깊이가 이 물 조각의 깊이보다 앞이면 전경으로 봤는데, 카메라 가까운 물속 바닥은 먼 수면보다 깊이 값이 작은 게 정상 | 전경 누출 = "찾은 표면이 그 자리 수면보다 위". 물 밖에 솟은 물체만 걸러짐. 이후 누출로 원래 픽셀을 쓴 곳 0~0.2% |
| 화면 아래쪽 넓은 띠가 굴절 없이 남아 경계가 생김 (lab_pillar_near 아래 15%) | 굴절된 시선이 화면 밖으로 나가면 바로 원래 픽셀로 돌아감 | 세기 ½, ¼로 다시 시도 → 경계가 3단계로 완만해짐 |
| 시선 오차가 큼 (lab_stairs 평균 3cm) | 거리 갱신 2회로는 깊은 바닥에서 덜 수렴 | 4회로 늘림 (`REFRACTION_STEPS`) |
| 4개 텍셀 Gather로 선형 보간 여부를 판정하던 첫 구현 | 판정 기준을 "수면 위 표면"으로 바꾸면 4개 모두 높이 역산이 필요해 비쌈 | 가장 가까운 텍셀을 그대로 읽음 (Load) |

### 관찰

- **깊은 물의 강한 압축과 조각남:** 물리값(세기 1)에서 8m 바닥은 실제보다 훨씬 얕게 압축되어 보이고(겉보기 깊이), 잔물결 기울기 × 긴 물속 거리 때문에 이동량이 커져 깊은 곳 무늬가 날카롭게 조각난다 (`after_step8/basic_lab_pillar_near.png` 왼쪽 위). 실제 물이라면 이 정도 깊이의 일렁임은 흐려 보인다. 얕은 Waterfront(수심 0.1~2.5m)에서는 자연스럽다. 아트 조절: 세기를 낮추거나, 나중에 잔물결과 큰 파도를 나눠 다른 세기를 줄 수 있다.
- **화면 공간의 한계:** 화면 밖, 다른 물체 뒤에 가려진 물속은 알 수 없다. 낮은 시점 화면 맨 아래, 받침대 경계 뒤가 그런 곳이다.
