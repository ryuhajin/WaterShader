## 1. 개념 설명 — 왜 이 장면부터 만드나

### 다음 단계가 하려는 일

2단계부터 물은 "물 아래에 이미 그려진 색"을 읽어서 바꾼다. 깊을수록 어둡고 물색에 가깝게.
그런데 **정답을 모르면 맞게 바뀌었는지 판단할 수 없다.** 그래서 깊이를 미리 아는 물체를 놓는다.

- **수신 표면**: 물 아래에서 빛을 받는 면 (바닥, 계단, 기둥의 잠긴 부분). 우리가 물 너머로 보는 대상.
- **수심** = 수면 높이 − 표면 높이 = 0 − y. 받침대 윗면이 y = −3이면 수심 3m.
- **통제된 비교**: 받침대 4개는 **색이 모두 같고 깊이만 다르다.** 나중에 색이 다르게 보이면 그 이유는 깊이 하나뿐이다.

### 지금 그리는 순서 (패스)

```text
1. 하늘            → HDR 색 버퍼
2. 불투명 물체     → HDR 색 버퍼 + 깊이 버퍼      ← 이번에 추가
3. 물 (아직 불투명) → 같은 HDR 색 버퍼에 덮어쓰기
4. 톤매핑          → 화면
```

물을 켜면 계단·받침대가 **전혀 안 보인다.** 3번이 2번 결과를 그 자리에서 덮어쓰기 때문이다.
이게 2단계의 질문이 된다:

- 물이 아래 색을 읽으려면, 덮어쓰기 **전에** 2번 결과를 따로 복사해 둬야 한다 → "물 없는 장면 색 복사본"
- 물이 "아래 표면이 얼마나 깊은지" 알려면 2번의 깊이를 읽어야 한다. 그런데 지금 깊이 버퍼는 **셰이더가 읽을 수 없는 형식**이다 → 형식 변경

### 디버그 뷰

`Scene Debug = Water depth (WP, m)`는 물을 숨기고 표면을 수심별 색으로 칠한다. 수심은 월드 위치(WP)의 높이로 계산한 미터 값(0 − y)이고, 깊이 버퍼와는 다르다. 선택하면 View 창에 색별 미터 범위가 표시된다.

| 색 | 수심 | Lab에서 해당하는 것 |
|---|---|---|
| 회색 | 수면 위 | 계단 윗부분, 기둥 윗부분, +5cm 받침대 |
| 하늘색 | 0 ~ 0.5m | 0.2m 받침대, −5cm 받침대, 자갈 구역(0.4m) |
| 초록 | 0.5 ~ 2m | 1m 받침대 |
| 노랑 | 2 ~ 4.5m | 3m 받침대 |
| 주황 | 4.5 ~ 7m | 6m 받침대 |
| 보라 | 7m ~ | 바닥(8m) |

- 경사·세로 면에 **1m마다 검은 등고선**, 수면 높이(y = 0)에 **빨간 선**.
- 디버그 색은 "빛"이 아니라 "데이터"라서 노출·톤매핑을 건너뛴다 (물 디버그 뷰와 같은 규칙).

## 2. 만든 것

### 장면 배치 (1 = 1m, 수면 y = 0)

**Water Lab** (`Graphics::BuildWaterLab`, 물 영역 24 × 24m)

| 물체 | 위치 / 크기 | 윗면 높이 | 무늬 |
|---|---|---|---|
| 바닥 | 24 × 24m | −8 | 체크 |
| 받침대 4개 | x = −6, −2, 2, 6 / z = 5, 3 × 3m | −0.2 / −1 / −3 / −6 | 눈금 |
| 계단 16단 | x −10 → −2, 폭 4m, 단 높이 0.25m, 단 너비 0.5m | +1.125 → −2.625 | 체크 |
| 기둥 | (3, −3.5), 지름 0.8m | +3 (바닥부터) | 눈금 |
| 수면 근처 받침대 | (6.5, −4.5) / (8.5, −4.5), 1.2 × 1.2m | −0.05 / +0.05 | 눈금 |
| 자갈 구역 | z = 10, 10 × 3m | −0.4 | 자갈 |

- 계단은 0.125m 어긋나게 시작해서 **어느 단도 수면(y = 0)에 걸치지 않는다** (평평한 물과 깜빡임 방지).
- 받침대·계단·근처 받침대는 **같은 색** (0.78, 0.75, 0.68).

**Waterfront 그레이박스** (`Graphics::BuildWaterfront`, 물 영역 80 × 80m, 철로는 +z 방향)

| 물체 | 윗면 높이 | 비고 |
|---|---|---|
| 해저 | −2.5 | 자갈 |
| 철로 자갈 둑 (폭 4.4m) | −0.35 | 자갈 |
| 침목 (0.65m 간격) | −0.23 | |
| 레일 | −0.08 | 8cm 잠김 |
| 승강장 (x 3.5 ~ 9.5, z 0 ~ 30) | +0.8 | 체크 |
| 승강장 계단 11단 (z 0 → −3.85) | +0.7 → −1.3 | 단 높이 0.2m |
| 전주 5개 + 팔 | +6 | 철로 양쪽 물속 |

### 코드

| 파일 | 내용 |
|---|---|
| `shaders/scene.hlsl` | 불투명 물체: 태양 Lambert + 환경광, 월드 좌표 무늬(체크·눈금·자갈), 수심 디버그 |
| `src/SceneShader.*` | 위 셰이더 클래스 (핫 리로드 포함, `SkyboxShader`와 같은 구조) |
| `src/Model.*` | 단위 박스·원기둥 생성 (`InitializeBox`, `InitializeCylinder`) |

| `CMakeLists.txt` | 새 소스, `scene.hlsl` 빌드 후 복사 |
| `assets/camera_presets.txt` | 슬롯 파일 v2 (장면 번호 추가, v1도 읽음) — 다음에 슬롯을 저장할 때 v2로 바뀜 |

- 자갈은 외부 텍스처 없이 셰이더에서 보로노이로 만든다. 멀어서 돌 하나가 픽셀보다 작아지면 평균 밝기로 바뀐다 (지글거림 방지).
- 물체는 양면으로 그린다. 닫힌 도형이라 뒷면은 어차피 가려지고, 생성한 삼각형 감기 방향을 컬링 설정에 맞출 필요가 없다.
